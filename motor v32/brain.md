## 2. FLUXO DE DADOS DO MOTOR (motor_v2/)

```
Promob (.promob=zip) ──export──▶ XML montado/explodido + DXF
        │                              │            │
        │                     ler_promob.ler_xml   cerebro_regras.ler_dxf
        │                     (R05, R06)            (R01, R02, R03)
        │                              ▼            ▼
        │                        cerebro_regras.Cerebro.executar()  ← 14 decisões logadas
        │                              ▼
        │                     sequencia.folhas_do_caderno (R10, R16)
        │                              ▼
        │     ┌────────────────────────┼─────────────────────────┐
        │  render_3d.modulo_3d   render_frontal.frente_frontal   cotas.cadeia_h/v
        │  (R07 portas fechadas) (R08/R12 sem interior+balões)   (R08 vermelhas)
        │      └────────────────────────┼─────────────────────────┘
        ▼                               ▼
material_map.carregar_paleta ──▶ gerar_caderno.gerar(config.json)
                                  = PDF A4 paisagem + carimbo por script (R09)
                                  + *_QUALIDADE.md (aprovação automática)
```

## 6. LACUNAS E CONTRADIÇÕES (cruzamento corpus × código)
1. **CAPA x sem CAPA** (resolvido — R16): baseline v6 começa em CAPA; os 16 cadernos reais começam em CONTRATO. Config decide (`com_capa`).
2. **Bug de carimbo existe nos PDFs reais**: CAROLINE SALA p4 carimbo diz "ÁREA DE SERVIÇO" e TACIANA SALA p4 idem — prova de que R09 (script) corrige defeito de produção da Origin.
3. **Ordem de colunas oscila** (Felipe Banho Solteiro: dim|desc; Caroline: desc|dim) — o parser de PDF de referência precisa aceitar as duas; o gerador do motor padroniza desc|dim.
4. **Descrições truncadas do XML** ("Armário c/ Portas de Giro c/ Ro", "Armário Despenseiro 200x1", typo "Amário") — a dimensão completa só está em WIDTH/HEIGHT/DEPTH; regra: confiar nos números, nunca no texto truncado.
5. **Medidas fracionárias com vírgula** (Armário Superior 728x**1539,79**x400) — `_num` já normaliza.
6. **Módulo-recorrente 865x730x715 "Balcão inferior"** aparece em 5 cadernos de 3 clientes → candidato a catálogo/miniatura padrão.
7. **Par idêntico cross-client** Balcão 2 Portas 760x605x470 + Tamponamento 605x18x70 (Felipe Banho Suíte = Caroline Banho Casal/Solteiro) → evidência de que regras são universais entre projetos.
8. **Render fotorrealista**: o motor gera 3D vetorial com paleta; textura exata do Promob depende do export OBJ/3DS (pendente no Drive).
9. **Painel Itapua / Tampo Curvo R155** (Taciana Sala): itens de fabricação própria sem módulo pai no XML — o classificador precisa do GROUPENTITY para enxergá-los como módulo avulso (já tratado em `modulo_avulso`).
10. **Notas ao montador e à cliente** (R13) ainda não têm placeholder no config — devem entrar como `notas: [{alvo: "vista/itens", texto: "SR. MONTADOR..."}]` (backlog do gerador).
